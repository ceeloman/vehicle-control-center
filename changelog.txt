Version: 1.2.1
  Features:
    - Neural Connections tab in the control center when Neural Spider Control is loaded.
    - Lists active and orphaned neural links under one Active Connections section with vehicle name and surface on a single line.
    - Connection rows use the same action buttons as normal vehicle rows (follow on map, locate, inventory, get remote, call spidertron) plus open engineer inventory, disconnect, or reconnect.
    - Open engineer inventory uses the player force icon.
---------------------------------------------------------------------------------------------------
Version: 1.2.0
Date: 2026-05-13
  Features:
    - Expanded GUI for browsing and controlling vehicles from one place.
    - Mods can plug in extra context buttons on spidertron, car, and spidertron-remote UIs; registrations persist in your save and are ordered by priority.
    - Added a custom map and whistle icons so row buttons still look right on Factorio 2.0
  Changes:
    - Neural Spider Control: vehicle connect now uses NSC's remote interface instead of loading their scripts directly, which is kinder to load order and updates.
    - Smarter "occupied" rules: "call here" only locks out when a real player is in the seat (dummy engineers from NSC don't count). Neural connect can defer to NSC's own rule when it exposes one.
    - "Get spidertron remote" prefers an empty cursor, can use a free inventory slot and swap onto the cursor when needed, and links using remote selection when the game supports it.
    - "Call spidertron here" falls back to your physical position when you're in map or remote mode, and won't send the spidertron to another surface by mistake.
    - Follow-on-map uses the mod’s map icon instead of a removed vanilla sprite.
    - Add GUI location persistence for vehicle control center. Implement functionality to remember and restore GUI position for players, enhancing user experience and interface consistency.
